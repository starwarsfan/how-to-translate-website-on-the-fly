# Traduire automatiquement des pages web

Ce guide explique, étape par étape, comment faire traduire automatiquement le contenu de **bonsai-vsb.ch** (ou de n'importe quel autre site) directement dans votre navigateur – par exemple en français ou en italien. Aucune application supplémentaire n'est nécessaire et rien n'a besoin d'être installé.

> **Remarque :** La traduction est générée automatiquement par ordinateur. Elle est généralement bien compréhensible, mais pas toujours parfaitement formulée. Pour un usage quotidien, elle est toutefois amplement suffisante.

## Ordinateur – Google Chrome

Google Chrome peut détecter et traduire automatiquement les pages web.

1. Ouvrez le site **bonsai-vsb.ch** dans Chrome.
2. En haut à droite, dans la barre d'adresse, une petite icône avec deux lettres (p. ex. « DE » ou un symbole de traduction) apparaît automatiquement. Cliquez dessus.
   - Si l'icône n'apparaît pas automatiquement : cliquez avec le bouton droit de la souris n'importe où sur la page et choisissez **« Traduire en français... »** (ou la langue souhaitée) dans le menu.
3. Dans la fenêtre qui s'affiche, choisissez la langue souhaitée (p. ex. français ou italien).
4. Chrome traduit immédiatement la page. Le texte reste traduit tant que vous restez sur cette page.
5. Pour revoir le texte original : cliquez à nouveau sur l'icône de traduction dans la barre d'adresse et choisissez **« Afficher l'original »**.

**Astuce :** Vous pouvez également configurer Chrome pour qu'il propose automatiquement une traduction pour ce site à l'avenir. Cliquez pour cela sur les trois points dans la fenêtre de traduction et choisissez l'option correspondante.

## Ordinateur – Microsoft Edge

Microsoft Edge dispose d'une fonction de traduction intégrée, très similaire à celle de Chrome.

1. Ouvrez le site **bonsai-vsb.ch** dans Edge.
2. Une icône de traduction (deux bulles de dialogue) apparaît à droite dans la barre d'adresse. Cliquez dessus.
   - Si elle n'apparaît pas : cliquez avec le bouton droit de la souris sur la page et choisissez **« Traduire dans votre langue »**.
3. Choisissez la langue souhaitée dans la fenêtre.
4. Cliquez sur **« Traduire »**.
5. Pour revenir à l'original : cliquez à nouveau sur l'icône de traduction et choisissez **« Afficher la page en allemand »**.

## Ordinateur – Mozilla Firefox

Firefox propose depuis quelques années une fonction de traduction intégrée respectueuse de la vie privée.

1. Ouvrez le site **bonsai-vsb.ch** dans Firefox.
2. Une icône de traduction apparaît à droite dans la barre d'adresse. Cliquez dessus.
   - Si elle n'apparaît pas : cliquez sur les trois traits (menu) en haut à droite et cherchez **« Traduire la page »**, ou vérifiez sous **Paramètres → Général → Langue** si la fonction de traduction est activée.
3. Choisissez la langue souhaitée dans la fenêtre et cliquez sur **« Traduire »**.
4. Pour revenir à l'original : cliquez sur l'icône de traduction et choisissez **« Afficher l'original »**.

## Ordinateur (Mac) – Safari

Safari sur Mac traduit également les pages web automatiquement.

1. Ouvrez le site **bonsai-vsb.ch** dans Safari.
2. Cliquez dans la barre d'adresse sur l'icône « aA » (réglages de la page) tout à gauche, ou repérez une icône de traduction à droite dans la barre d'adresse.
3. Choisissez **« Traduire la page »** ou **« Traduire en... »** dans le menu.
4. Choisissez la langue souhaitée.
5. Pour revenir en arrière : ouvrez à nouveau le même menu et choisissez **« Afficher l'original »**.

## iPhone / iPad – Safari

1. Ouvrez le site **bonsai-vsb.ch** dans Safari sur votre iPhone ou iPad.
2. Appuyez en bas (ou en haut, selon l'appareil) sur l'icône « aA » dans la barre d'adresse.
3. Dans le menu qui s'ouvre, appuyez sur **« Traduire en [langue] »**.
   - Si cette option n'apparaît pas, appuyez plutôt sur **« Réglages du site »** et cherchez-y l'option de traduction.
4. Choisissez la langue souhaitée dans la liste.
5. La page s'affiche désormais traduite.
6. Pour revenir à l'original : appuyez à nouveau sur l'icône « aA » et choisissez **« Afficher l'original »**.

## Téléphone/tablette Android – Google Chrome

1. Ouvrez le site **bonsai-vsb.ch** dans Chrome sur votre appareil Android.
2. Une petite fenêtre apparaît généralement automatiquement en bas de l'écran avec une proposition de traduction.
   - Si ce n'est pas le cas : appuyez en haut à droite sur les trois points (menu) et choisissez **« Traduire »**.
3. Choisissez la langue souhaitée.
4. Appuyez sur **« Traduire »**.
5. Pour revenir à l'original : appuyez en haut à droite sur les trois points et choisissez **« Afficher l'original »**, ou appuyez sur l'icône correspondante dans la petite fenêtre de traduction.

## Questions fréquentes

**La traduction est-elle sûre / mes données sont-elles transmises ?**
La traduction est effectuée en arrière-plan par Google, Microsoft ou Mozilla. Pour consulter un site associatif public, cela ne pose aucun problème.

**La traduction n'est pas parfaite – est-ce normal ?**
Oui. Les traductions automatiques sont généralement bien compréhensibles, mais pas toujours formulées avec une précision linguistique parfaite. En cas de doute, n'hésitez pas à contacter le comité.

**Dois-je installer quelque chose ?**
Non. Toutes les fonctions décrites ici sont déjà intégrées aux navigateurs mentionnés.

**Que faire si mon navigateur ne propose aucune de ces options ?**
Assurez-vous que votre navigateur est à jour (mise à jour via l'App Store, le Google Play Store ou les réglages du navigateur). Sur des versions de navigateur très anciennes, la fonction de traduction est parfois absente.

---

*Ce guide s'applique en principe à tous les sites web, pas seulement à bonsai-vsb.ch.*
